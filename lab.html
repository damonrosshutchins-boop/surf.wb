Learning goals

  • Separate a simplified mathematical model from observed game behavior.
  • Compare the effects of slope angle and elapsed time.
  • Record repeatable trials and identify sources of variation.

The linked surf game uses its own movement rules. This calculator is a separate idealized model, not a measurement of that game.

1. Predict with an ideal ramp

For an object starting from rest on a straight frictionless ramp, use a = g sin(theta), v = at, and d = at squared / 2. Here g = 9.81 m/s squared. This ignores air resistance, friction, collisions, and player input.

Choose values and calculate a prediction.

2. Test in the surf game

  1. Write a prediction about which movement technique will produce a faster run.
  2. Open the surf game in another tab. Choose a repeatable route and starting point.
  3. Change only one input technique at a time. Keep the route and starting conditions as consistent as possible.
  4. Repeat each technique three times. Record the displayed speed if available and the completion time.

Game speed units are not necessarily meters per second. Do not compare them directly with the calculator without a documented conversion.
