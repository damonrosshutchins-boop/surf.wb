## Deployment

The GitHub Actions workflow in `.github/workflows/static.yml` builds the repository with Jekyll and deploys `_site` to GitHub Pages on pushes to `main`. The workflow can also be started manually. Configure Settings > Pages > Source to use GitHub Actions.

Follow the rules of the device and network you use. Deployment changes do not override network access policies. For deployment errors, inspect the repository's Actions runs. For loading problems, report the browser, error message, and reproduction steps without including personal information.
